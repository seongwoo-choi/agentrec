# agentrec v0.10.1

Command help is now safe and discoverable across every documented top-level
command.

## What changed

- `agentrec <command> -h` and `agentrec <command> --help` now print that
  command's usage to stdout and exit with status `0`.
- Help is resolved before command dispatch, so requests such as
  `agentrec start --help`, `agentrec stop --help`, and
  `agentrec setup --help` perform no command action.
- Unknown commands remain errors; prefixes are not accepted as abbreviations.
- `agentrec trash --help` now includes the supported `sweep <age> [--dry-run]`
  option.

## Upgrade

Download the matching native archive from the GitHub release page or upgrade
with Homebrew:

```bash
brew update
brew upgrade seongwoo-choi/tap/agentrec
agentrec version --verbose
```

Direct Go installation remains available:

```bash
go install github.com/seongwoo-choi/agentrec/cmd/agentrec@v0.10.1
```

## Trust boundary

Help output is derived from the built-in public command synopsis. An exact
`-h` or `--help` request for a documented top-level command returns before its
parser or action runs; it does not start or stop the viewer, alter provider
configuration, or write run data.
