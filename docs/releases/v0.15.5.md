# agentrec v0.15.5

This patch makes dense Viewer evidence easier to navigate by keyboard and improves CLI command discovery without weakening the recorded evidence boundary.

## What changed

### Viewer navigation and accessibility

- Conversation rows now expose separate native controls for selecting evidence and expanding recorded text. Exact links, inspector selection, keyboard activation and focus survive search, filters, history and locale changes.
- Repeated action controls include a localized loaded-stream position in their accessible names. This distinguishes similar rows without inventing a record-wide rank or changing visible evidence.
- Selecting different action, change or provider-event evidence resets only the inspector's internal scroll, so the new title is visible. Same-evidence rerenders preserve the reader's position.
- Shared comparison links place initial focus inside the modal while bundles load. Ordinary **Compare with…** opens still focus the run picker.
- Global search results no longer become a separate Tab stop. Tab or Shift+Tab closes the overlay and cancels pending or in-flight search ownership before native focus moves; late responses cannot reopen it. Arrow, Enter, pointer and exact-link behavior remain.

### CLI discovery

- `agentrec help` prints root help, and `agentrec help <command>` supports every documented public root and nested topic without executing the command. Unsupported suffixes and hidden topics still fail.

Stored raw evidence, failures, unknown states, identifiers and byte cursors remain unchanged. Loaded-stream positions do not claim record-wide ordering, and notification-shaped text still does not establish automated provenance.

## Upgrade

```bash
brew update
brew upgrade seongwoo-choi/tap/agentrec
agentrec version --verbose
```

Direct Go installation:

```bash
go install github.com/seongwoo-choi/agentrec/cmd/agentrec@v0.15.5
```
