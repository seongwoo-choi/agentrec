# agentrec v0.15.4

This patch makes stale or incomplete Viewer data explicit and keeps resumed-session usage scoped to the current recording.

## What changed

### Viewer evidence correctness

- Successful run-list, search, action, provider-event and repository-change responses now require their mandatory collections. Missing collections surface contract errors instead of false-empty states, while previously loaded evidence remains available.
- Comparison refreshes preserve the latest valid runner capability, execution permission and job identity. Unavailable runners stay disabled and are omitted from copied commands; stale responses cannot overwrite newer state.
- Failed live refreshes now keep the last successful update time, show a localized non-animated stale-evidence indicator and announce failure and recovery. Partial working-tree refresh failures remain visibly qualified.

### Resumed-session attribution

- Session usage starts at the boundary captured before hook delivery can be acknowledged, so a provider response from an earlier recording is not counted merely because it falls inside startup metadata skew.
- Timestamp-less usage is excluded when that session boundary applies. Claude model attribution follows counted responses, while Codex turn context is attributed only when a current token-count record is counted.

Stored raw evidence, failures, unknown states, identifiers and cursors remain unchanged. No provenance, causality or verification success is inferred.

## Upgrade

```bash
brew update
brew upgrade seongwoo-choi/tap/agentrec
agentrec version --verbose
```

Direct Go installation:

```bash
go install github.com/seongwoo-choi/agentrec/cmd/agentrec@v0.15.4
```
