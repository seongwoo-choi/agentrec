# agentrec v0.15.7

This patch keeps recorded failures and exact evidence identities visible across CLI and Viewer boundaries.

## What changed

### Viewer evidence accuracy

- Unreadable-run warnings from loaded continuation pages now survive first-page polling, and the Viewer offers widening only while another page can actually be loaded.
- Viewer list and detail responses retain a supervisor-observed process ending when final manifest installation did not preserve it. Process and verification failures stay independent.
- Copied action evidence links now use each record's exact JSONL byte offset, so actions with the same ID reopen the selected evidence instead of a different record.

### Stored-evidence integrity

- `status` now rejects the same invalid trash roots as trash commands instead of hiding them.
- Verification results with duplicate or case-fold-equivalent JSON members are unreadable rather than allowing a later member to replace an earlier failure verdict.
- `events` requires the recorded manifest identity before interpreting or attributing provider-event artifacts.

Original payloads, identifiers, byte cursors, unknown states and failures remain explicit. None of these checks turns provider-reported evidence into independent proof or rewrites canonical stored documents.

## Upgrade

```bash
brew update
brew upgrade seongwoo-choi/tap/agentrec
agentrec version --verbose
```

Direct Go installation:

```bash
go install github.com/seongwoo-choi/agentrec/cmd/agentrec@v0.15.7
```
