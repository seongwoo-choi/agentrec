# agentrec v0.15.3

This patch makes the Viewer easier to navigate with a keyboard or assistive
technology and closes two CLI correctness gaps.

## What changed

### Viewer navigation and accessibility

- The focused run-evidence destination now has the current run title as its
  concise accessible name instead of exposing the complete descendant tree.
- Active project and verification overview groups expose synchronized visual
  and assistive pressed state, retain exact keyboard focus across rerenders,
  and toggle off when activated again.
- The run whose evidence is currently displayed exposes a localized current
  description with its exact run ID across selection and locale changes.

### CLI correctness and usability

- Trailing `-h` and `--help` now show command-specific help after operands or
  options while remaining ordinary provider input after `--`.
- `agentrec list --cwd` matches the canonical working-directory identity stored
  with each run, preserving deleted-path lookup and rejecting retargeted aliases.
- Returned stdout errors and short writes no longer allow plain-text commands to
  report success without delivering their output. Existing nonzero command
  exits remain intact and the output failure is diagnosed separately.

Stored evidence, failures, unknown states, identifiers and cursors remain
unchanged. No provenance, causality or verification success is inferred.

## Upgrade

```bash
brew update
brew upgrade seongwoo-choi/tap/agentrec
agentrec version --verbose
```

Direct Go installation:

```bash
go install github.com/seongwoo-choi/agentrec/cmd/agentrec@v0.15.3
```
