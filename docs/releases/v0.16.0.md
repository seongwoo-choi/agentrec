# agentrec v0.16.0

This release makes recorded requests and recorder health directly inspectable without turning configuration or provider-reported events into stronger evidence than they are.

## What changed

### Recorded-request navigation

- Run details now show a bounded recorded-request index without downloading the full action stream.
- Selecting a request opens its exact `user.prompt` action by JSONL byte offset, including prompts beyond the first action page.
- Empty or duplicate action IDs remain navigable by exact byte offset; malformed cursors and ID/offset mismatches fail closed instead of selecting a different action.

### Truthful recording status

- `status` and the Viewer distinguish active, ended, failed and unknown recording states from hook-installation diagnostics.
- The display separates the latest recorder-observed event time from the time status was refreshed.
- Hook configuration remains diagnostic only: it does not claim that events arrived, recording is healthy or evidence was persisted.

Original payloads, identifiers, byte cursors, unknown states and failures remain explicit. Request navigation is a projection over the unchanged recorded action stream, not a causal grouping or proof of human origin.

## Upgrade

```bash
brew update
brew upgrade seongwoo-choi/tap/agentrec
agentrec version --verbose
```

Direct Go installation:

```bash
go install github.com/seongwoo-choi/agentrec/cmd/agentrec@v0.16.0
```
