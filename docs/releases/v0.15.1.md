# agentrec v0.15.1

This patch keeps the Viewer faithful when prompts or titles cross display and
pagination boundaries.

## What changed

- Prompt ordinals now keep their record-wide position when an exact action link
  opens a nonzero byte-cursor page. Duplicate or missing action IDs do not merge
  positions, and missing rank evidence stays unlabeled instead of becoming a
  plausible page-local rank.
- JSONL cursor accounting now preserves exact byte offsets for CRLF, blank lines
  and a final record without a newline.
- Text matching the `<task-notification>` shape is labelled
  **Notification-shaped prompt**. The label describes observed syntax without
  inferring an unrecorded sender or notification origin.
- The run-detail heading now shows the complete already-redacted, 120-rune
  loaded title instead of cutting it again at the first sentence. Sidebar and
  request disclosure behavior is unchanged.

Original records, search results, inspector payloads and exact evidence links
remain available. These changes alter display projection only; they do not
infer causality, authorship or verification success.

## Upgrade

```bash
brew update
brew upgrade seongwoo-choi/tap/agentrec
agentrec version --verbose
```

Direct Go installation:

```bash
go install github.com/seongwoo-choi/agentrec/cmd/agentrec@v0.15.1
```
