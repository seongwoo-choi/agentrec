# agentrec v0.15.2

This patch makes recorded evidence easier to navigate and harder to misread or
silently lose at CLI and Viewer boundaries.

## What changed

### Viewer navigation and accessibility

- Run rows expose the exact recorded start time without adding visible noise;
  missing or invalid starts remain **unknown**.
- On narrow screens, selecting a run reveals its evidence and **Back to runs**
  returns to the focused run list. Failed, superseded, history and desktop loads
  keep their previous scroll behavior.
- Repeated conversation disclosures include localized speaker and prompt-position
  context for assistive technology.
- The timeline row currently shown in the inspector exposes a localized,
  non-toggle current state across exact links, filters, history and live refresh.
- Successful HTTP responses with malformed JSON now show an explicit error
  instead of a false-empty run or action list. Polling preserves the last valid
  list while surfacing the contract failure.

### Recorder and evidence correctness

- Hook-driven `session serve --verify` processes now return a failing exit status
  after filing a non-passing verification result.
- A held session lock is treated as healthy only after a bounded,
  session-specific liveness exchange with the recorder.
- Untracked-file capture is bounded to the size observed when the file is opened
  and checks cancellation between chunks.
- Provider records reach in-memory parsers only after bounded evidence storage
  accepts them; rejected records are still drained without unbounded retention.
- Stored process durations must be present, non-null, non-negative and safely
  convertible. Invalid bundles fail closed across CLI and Viewer reads.

Records accepted into the evidence bundle retain their errors, unknown states,
identifiers, cursors and exact links. No sender, causality or verification success
is inferred.

## Upgrade

```bash
brew update
brew upgrade seongwoo-choi/tap/agentrec
agentrec version --verbose
```

Direct Go installation:

```bash
go install github.com/seongwoo-choi/agentrec/cmd/agentrec@v0.15.2
```
