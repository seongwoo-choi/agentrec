# agentrec v0.17.0

## What changed

- Open a recorded request's chronological interval in the Viewer, ending before the next recorded prompt or at the current snapshot boundary. Exact links preserve the request scope; leaving it restores the complete timeline.
- Terminal, Markdown and JSON summary fields no longer call a completed shell action successful when no integer exit code was reported. They say `completed (exit code not reported)`. Explicit exit codes and failures retain their existing behavior.

Request intervals do not establish causality or pair prompts with replies. Missing exit codes are not inferred from command output, and failure filters are unchanged. Existing stored reports are immutable: use `agentrec show <run-id>` for a freshly rendered summary.

## Real-use validation

Actual Claude Code 2.1.266 and Codex 0.150.1 sessions built and used a local inventory-report utility. Both providers handled multiple requests, ended and resumed with the same provider session identity. The resumed Codex recording ran a Git-pinned independent check after SessionEnd and recorded PASS. Parent-executed tests and provider-reported test output are not substituted for that independent verification.

Recorded-request navigation, exact action identity, command result inspection and tracked patches were exercised in an isolated Chrome viewer. See [the bounded evidence report](../dogfood/2026-09-29-real-provider-sessions.md) for scope and limitations.

## Upgrade

```bash
brew update
brew upgrade seongwoo-choi/tap/agentrec
agentrec version --verbose
```

```bash
go install github.com/seongwoo-choi/agentrec/cmd/agentrec@v0.17.0
```

Upgrading the executable does not replace an already-running Viewer. Restart your Viewer when ready to adopt the new version.
