# agentrec v0.21.0

## See when the provider could not run a turn

When Claude Code ends a turn on an API error — rate limit, authentication, billing and the like — it sends a `StopFailure` hook instead of `Stop`. agentrec now registers it and files the turn as a `provider.error` with the provider's error code, details and message verbatim. The run detail shows the last such error beside the request, with its position and a link to the original record.

Before this, a session whose provider failed before doing any work looked the same as one that had not answered yet: a prompt, no reply, no reason.

- It is the provider's own report of a turn it could not complete, not a verdict on the run. Run status, repository observations and independent verification are unchanged.
- Error codes and messages are shown literally; nothing is classified, retried or inferred. The Viewer shows up to 4 KiB per field and says when it cut one; the action record keeps the full report. If a payload was too large to record, the error code is still kept.
- Codex has no equivalent hook. A Codex turn that could not run still appears only as a prompt without a reply.
- Existing records are not rewritten. Failures before this release were never recorded and cannot be recovered.

## Development evidence

Recording, viewer and registration tests were committed failing first. The motivating observation came from real sessions that ended on a Codex usage limit, an expired Claude OAuth session and a revoked token; each left a record indistinguishable from an unanswered prompt. This release also includes the same-session link regression tests merged after v0.20.0.

## Upgrade

```bash
brew update
brew upgrade seongwoo-choi/tap/agentrec
agentrec setup --claude
agentrec version --verbose
```

```bash
go install github.com/seongwoo-choi/agentrec/cmd/agentrec@v0.21.0
```

`agentrec setup --claude` adds only the missing `StopFailure` hook and keeps every other hook in place; `agentrec status` reports a partial installation until then. Keep `--verify` or `--project` if the existing installation used them. Restart the Viewer to use the installed version.
