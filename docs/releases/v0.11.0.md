# agentrec v0.11.0

The Viewer can now find a recorded repository change by path across every stored
run and open the exact file row and inspector.

## What changed

- Global Viewer search includes validated tracked and untracked change paths from
  stored canonical repository evidence.
- Selecting a change result opens its run, switches to Changes, loads the exact
  paginated row, and opens that row in the inspector.
- Existing timeline filters are cleared when they would hide a directly selected
  search result.
- Search covers the full bounded change inventory rather than only its first
  page, while retaining the existing hit and time limits.
- Request cancellation and deadlines propagate through run listing, action
  scanning, and repository-change scanning.

## Upgrade

```bash
brew update
brew upgrade seongwoo-choi/tap/agentrec
agentrec version --verbose
```

Direct Go installation remains available:

```bash
go install github.com/seongwoo-choi/agentrec/cmd/agentrec@v0.11.0
```

## Trust boundary

Among repository-change evidence, this release adds only stored path metadata to
the existing index. Existing run and project metadata, prompts, action types, and
allowlisted action-input fields remain searchable. Patch text, file contents,
and raw provider payloads are not added. Repository evidence is validated before
paths are indexed, and search remains read-only and bounded.
