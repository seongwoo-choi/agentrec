# agentrec v0.2.0

A run-centric evidence viewer and isolated multi-agent comparison release.

## What changed

- **Read-only local viewer** — `agentrec view [run-id|latest]` serves immutable
  loopback-only snapshots with paged actions, provider events, repository changes,
  and bounded sanitized patches.
- **Change Explorer** — tracked, untracked, binary, addition, and deletion evidence
  is separated from unavailable or malformed capture states.
- **Unified Overview** — process outcome, verification verdict, validated repository
  evidence, actions, events, duration, and warnings appear together without
  converting unavailable evidence into success.
- **Same-path observations** — explicit file-action paths are projected into the
  repository namespace at record time and can be matched with changed paths. The
  viewer labels these links `same path observed — not causal proof`; command and
  result text are never inferred as paths.
- **`agentrec shadow run`** — Claude and Codex can execute the same task in isolated
  worktrees from one baseline. Comparison groups preserve each leg and do not
  manufacture a winner or score.
- **Provider-event and usage evidence** — bounded provider events, unparsed stdout,
  and provider-reported token usage remain separate from normalized actions.
- **Operational controls** — provider timeout, list filters, unsupported-version
  markers, stronger process cleanup, Git index drift detection, and immutable
  snapshot/file-handle boundaries.
- **Localized documentation** — English, Korean, Japanese, and Simplified Chinese
  READMEs share executable commands and safety contracts.

## Homebrew rollout

Release archives publish first. The separate public tap updater then validates
the v0.2.0 Formula with a real `brew install` and `brew test`; until that update
completes, Homebrew remains on the previous release. After the Formula is live:

```bash
brew install seongwoo-choi/tap/agentrec
```

Release archives are available for `darwin_amd64`, `darwin_arm64`,
`linux_amd64`, and `linux_arm64`, with all four covered by `SHA256SUMS`.

## Trust boundaries

- Repository deltas and same-path observations are not causal attribution.
- `UNAVAILABLE` evidence is neutral, never a pass.
- The viewer is read-only, binds only to loopback, and loads no external assets.
- Release archives remain unsigned and unnotarized; checksums establish artifact
  identity, not publisher signatures.
- Windows remains unsupported.
