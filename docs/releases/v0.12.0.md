# agentrec v0.12.0

Return to the exact recorded action, not just its run. Action links now preserve
an action ID and its page's byte cursor across reloads and browser history.

## What changed

- Action search results open a shareable exact-action destination. Reload, Back,
  and Forward restore the matching action and evidence inspector.
- Selecting another action updates the link, including actions loaded by later
  pages. Cursors remain JSONL byte positions, never inferred row numbers.
- Ordinary evidence tabs clear exact selection and restore ordinary page-zero
  navigation when leaving an exact or pending page.
- Pending run and page requests are superseded through the existing cancellation
  and generation checks. An older response cannot clear a newer exact selection.
- Stale outgoing rows, including re-rendered rows, cannot attach their action to
  a different incoming run's URL. Existing changed-file links remain supported.
- English, Korean, Japanese, and Simplified Chinese documentation describes the
  same action-link workflow.

## Upgrade

```bash
brew update
brew upgrade seongwoo-choi/tap/agentrec
agentrec version --verbose
```

Direct Go installation:

```bash
go install github.com/seongwoo-choi/agentrec/cmd/agentrec@v0.12.0
```

## Trust boundary

Action destinations use `run`, `focus=actions`, `action`, and `actionCursor`.
They identify existing recorded evidence; they neither run a command nor change
canonical evidence. An absent action is not replaced with another action, and
invalid cursor syntax cannot select an exact target. Per-page cursor metadata
is a Viewer projection, not a storage-format change. Existing bounded snapshot,
redaction, loopback, and provider-versus-observer boundaries remain unchanged.
