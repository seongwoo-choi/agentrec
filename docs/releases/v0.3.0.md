# agentrec v0.3.0

Interactive sessions can now be recorded, and the evidence a run leaves is
harder to rewrite.

## What changed

- **Interactive session recording** — `agentrec hooks print --claude` and
  `agentrec hooks print --codex` print a hooks fragment; every session opened
  after it is installed is recorded from the session's own hooks by a
  per-session recorder (`agentrec hook`, `agentrec session serve`). The bundle
  has the shape of a traced run's, and the report states what differs: the
  supervisor section reads `UNAVAILABLE` with the session named and `Ended By`
  saying whether the session's `SessionEnd` hook reported the end or the
  recorder gave up waiting; the repository evidence carries a `Window` line,
  because the baseline is pinned when the first hook arrives and the checkout
  was open throughout; verification runs only for a fragment printed with
  `--verify`, and only against a committed `.agentrec.yaml` identical to
  `HEAD`. A dirty checkout and concurrent sessions are recorded rather than
  refused. No delivery can end the recording of the ones after it, and a session
  resumed under the same ID gets a recorder of its own.
- **Codex sessions** — the same recorder takes Codex's hooks, which carry the
  same fields. Codex sends no `PostToolUseFailure`; `apply_patch` edits take
  their repository paths from the patch headers. Payload shapes were confirmed
  against Codex 0.150.1 in `codex exec`; a full interactive TUI turn was not
  verified on the release machine.
- **Redaction no longer grows a line past the stream limit** — `<`, `>` and `&`
  are written as they are instead of as six-byte escapes, so a provider event
  that fit before redaction still fits after it and cannot poison the rest of
  the bundle. The rule version is unchanged: which secrets are redacted is not.
- **Repository evidence is pinned to Git's defaults** — the tracked diff runs
  with textconv, colour, prefixes, context, algorithm and indent heuristic
  fixed on the command line, and every evidence command runs with
  `core.fsmonitor` off, so repository attributes and operator configuration
  cannot rewrite the patch. Git waits are bounded even when a filter or hook
  outlives Git holding its pipes.
- **A repository mid-revert is refused**, like one mid-merge or mid-rebase.
- **Viewer and readers** — `session_lost` renders as a failure class, the
  viewer shows the session's evidence window and names the mode and session,
  and `agentrec events` summarises hook payloads by their event name.

## Upgrading

Runs recorded by earlier releases read as before: a manifest without a mode is
a traced run. Hooks installed from the fragment call the binary by absolute
path, so a binary moved after installation needs the fragment printed again.

## Homebrew rollout

Release archives publish first. The separate public tap updater then validates
the v0.3.0 Formula with a real `brew install` and `brew test`; until that update
completes, Homebrew remains on the previous release. After the Formula is live:

```bash
brew upgrade agentrec
```

Release archives are available for `darwin_amd64`, `darwin_arm64`,
`linux_amd64`, and `linux_arm64`, with all four covered by `SHA256SUMS`.

## Trust boundaries

- A session's end is the provider's report, not an observation: anything
  running as the operator can send a `SessionEnd`, and the report says so.
- The baseline of a session is pinned when its first hook arrives, not before
  the process started, and the checkout was open to the operator in between.
- Hooks a session disables leave a gap, not an absence.
- Repository deltas and same-path observations are not causal attribution.
- `UNAVAILABLE` evidence is neutral, never a pass.
- The viewer is read-only, binds only to loopback, and loads no external
  assets; it is not authenticated against other users of the same host.
- Release archives remain unsigned and unnotarized; checksums establish
  artifact identity, not publisher signatures.
- Windows remains unsupported.

Each archive contains `agentrec`, `LICENSE`, `THIRD_PARTY_NOTICES.md`, and
`third_party/licenses/Apache-2.0.txt`. The binary reports the tag, full commit
SHA, and UTC build timestamp through `agentrec version`.
