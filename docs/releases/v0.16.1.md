# agentrec v0.16.1

This patch keeps independent `status` diagnostics visible when the latest recording evidence cannot be read.

## What changed

- `agentrec status` still exits with failure and reports the unreadable latest recording evidence.
- Trash usage, Viewer-cache usage and Claude/Codex hook diagnostics are now printed before that failure is returned.
- A regression test preserves the complete diagnostic output on this error path.

The immutable v0.16.0 release remains unchanged.

## Upgrade

```bash
brew update
brew upgrade seongwoo-choi/tap/agentrec
agentrec version --verbose
```

Direct Go installation:

```bash
go install github.com/seongwoo-choi/agentrec/cmd/agentrec@v0.16.1
```
