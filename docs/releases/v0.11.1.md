# agentrec v0.11.1

Keep the exact changed file open when returning to recorded evidence. Viewer
links now preserve the file path and cursor across reloads and browser history.

## What changed

- Changed-file links restore the matching Changes row and inspector on reload,
  Back, and Forward, including files beyond the first page.
- Selecting another file updates its link. Ordinary tab navigation clears the
  exact-file destination when it clears the selection.
- Returning to a plain Changes link restores page zero instead of retaining a
  later page. Exact-link restoration clears stale timeline text filters.
- Outgoing rows cannot attach an old file path to an incoming run's URL, even
  when those rows are re-rendered while the new run's response is delayed.
- Search responses explicitly include the first changed file's index `0`.
  Once action results exceed the hit limit, search skips further change capture.
- Changed-file search badges now follow the selected Korean, Japanese, or
  Simplified Chinese language; localized README terminology is consistent.

## Upgrade

```bash
brew update
brew upgrade seongwoo-choi/tap/agentrec
agentrec version --verbose
```

Direct Go installation:

```bash
go install github.com/seongwoo-choi/agentrec/cmd/agentrec@v0.11.1
```

## Trust boundary

Links identify stored evidence with `run`, `focus`, `change`, and `changeCursor`.
They do not authorize filesystem access or establish that an agent caused a
change. Invalid cursor syntax or an absent target does not select a substitute
file. Repository-change search still indexes validated path metadata, not patch
text or file contents; existing run, prompt, and allowlisted action-field search
remains available. All Viewer reads stay within the existing loopback-only,
bounded evidence interface.
