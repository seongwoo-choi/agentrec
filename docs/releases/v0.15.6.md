# agentrec v0.15.6

This patch makes selected evidence easier to reach and strengthens failure reporting at the session, verification and Viewer boundaries.

## What changed

### Viewer navigation and failure states

- A selected action, change, provider event or live change now offers one keyboard-accessible jump to the **Evidence inspector**. Activating it moves focus to the inspector without changing the selected evidence, its exact link or browser history.
- Both run-deletion confirmation choices now expose the localized confirmation question to assistive technology.
- Valid zero-change pages serialize an empty array, so the Viewer shows its ordinary empty Changes state instead of a false response-contract error.

### Session and verification reliability

- Session shutdown now files every delivery already accepted and acknowledged by the recorder, including entries queued after `SessionEnd`, while preserving the single evidence writer and queue order.
- `verify latest` refuses to guess when an unreadable run directory makes ordering ambiguous. Exact run-ID verification remains available.
- A session recorder now exits nonzero if final manifest installation fails, after attempting repository capture, requested verification and report close-out.

Original payloads, identifiers, byte cursors, unknown states and failures remain explicit rather than being replaced with inferred success. Hook acknowledgement still means acceptance into the recorder process, not durable storage.

## Upgrade

```bash
brew update
brew upgrade seongwoo-choi/tap/agentrec
agentrec version --verbose
```

Direct Go installation:

```bash
go install github.com/seongwoo-choi/agentrec/cmd/agentrec@v0.15.6
```
