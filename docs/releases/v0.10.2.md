# agentrec v0.10.2

Help now follows users into every documented grouped command path instead of
interpreting `--help` as an identifier, age, or action argument.

## What changed

- `shadow run`, `shadow show`, `hooks print`, `trash restore`, `trash empty`,
  and `trash sweep` now accept exact `-h` and `--help` requests.
- Nested help prints only the matching command path's usage to stdout, exits
  with status `0`, and returns before command dispatch.
- Help matching preserves argv token boundaries. A single token such as
  `"shadow run"` and abbreviated paths remain errors rather than aliases.
- The root synopsis lists the three `trash` actions separately, including the
  optional `trash sweep <age> [--dry-run]` flag.

## Upgrade

```bash
brew update
brew upgrade seongwoo-choi/tap/agentrec
agentrec version --verbose
```

Direct Go installation remains available:

```bash
go install github.com/seongwoo-choi/agentrec/cmd/agentrec@v0.10.2
```

## Trust boundary

Only command paths explicitly present in the built-in public synopsis qualify
for nested help. Help resolution happens before repository, trash, provider
configuration, or viewer actions, so it does not inspect identifiers or mutate
local state.
