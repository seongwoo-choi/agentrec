# agentrec v0.18.0

## Read the new files a run left behind

In **Changes**, select a stored untracked file and choose **View stored text**. The Viewer reads the recorded, sanitized body only after validating its SHA-256 identity. It never substitutes today's workspace file. Missing, changed, unsupported or oversized bodies are explicitly unavailable; verified empty text is valid. Reads are bounded to 1 MiB and text is displayed literally, not interpreted as HTML.

## Keep navigation and loading honest

- Rapid request-scope exit followed by a Changes-tab switch no longer lets a late same-run response erase a newer selection. Outgoing evidence is visibly loading and noninteractive until replacement is ready.
- A snapshot-only refresh discards stale stored-text responses while allowing the owning loading control to settle and retry against the current snapshot.
- Error wrappers follow in-place language changes without modifying recorded diagnostics.

Repository observations remain noncausal. Run-wide independent verification is not a verdict on an individual request. Existing recordings are not rewritten.

## Verification scope

The merged implementation passed full Go, race, vet, build, localization and UI checks (361 UI tests), independent correctness/security and behavioral review, and CI on its merge commit. Real recorded bodies were compared by digest in 16 browser cases across two files, four languages and two screen widths. Controlled timing/error fixtures exercised navigation and loading separately from actual-record checks. This is not a claim of native execution on every archive platform or of all possible races being absent.

## Upgrade and adopt

```bash
brew update
brew upgrade seongwoo-choi/tap/agentrec
agentrec version --verbose
```

```bash
go install github.com/seongwoo-choi/agentrec/cmd/agentrec@v0.18.0
```

An already-running Viewer keeps its old executable. Restart your identified Viewer when ready; installing a new binary alone does not change the open page. Hook configuration and existing evidence remain separate from Viewer adoption.
