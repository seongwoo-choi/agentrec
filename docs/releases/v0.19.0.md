# agentrec v0.19.0

## Read one request's observed work together

A selected recorded request interval now has an expandable, bounded index of loaded file mentions and command observations, with exact links to the original action records. It does not fetch an entire run or replace the original timeline.

- Loaded-only, partial and open-interval boundaries remain explicit.
- Recorded status and structured exit evidence stay separate. Completion without a reported exit code is not success; output text is not parsed into a verdict.
- File mentions are not proof of repository changes or causality. Command order does not establish a retry or recovery.
- Run-wide independent verification stays separate from the request index.
- Localized controls preserve original record content and exact byte-offset navigation.

The preceding v0.18.0 release introduced stored-new-file text inspection and navigation fixes. This release adds the request observation view; it does not rewrite historical evidence.

## Test tooling security

The development-only undici dependency is updated from 8.10.1 to 8.11.2. Audit checks include development dependencies explicitly; an inherited production environment must not hide test-tooling advisories. This package is not a runtime dependency of the distributed Go executable.

## Upgrade

```bash
brew update
brew upgrade seongwoo-choi/tap/agentrec
agentrec version --verbose
```

```bash
go install github.com/seongwoo-choi/agentrec/cmd/agentrec@v0.19.0
```

An existing Viewer keeps its previous executable until restarted. Preserve its listen address and recording configuration when adopting the new version.
