# agentrec v0.14.0

Copy a link to the recorded action or changed file you are inspecting, without
carrying unrelated sidebar filters or comparison state into that link.

## What changed

- A selected recorded action or stored changed-file row offers a local
  evidence-link copy button. Action links retain their byte-page cursor;
  changed-file links retain their absolute list index.
- Canonical links contain the run, evidence kind, exact target and cursor. They
  omit sidebar search/project/exit/verification filters and comparison hashes.
- Copy success is shown only after the clipboard write resolves for the still
  valid target. Late outcomes cannot label a different selection or run.
- When the clipboard is unavailable or denied, a readonly selectable URL and
  manual-copy guidance remain available for the current target.
- An asynchronous patch refresh of the same selected file preserves the copy
  controls, pending outcome, recovery URL, focus and input selection range.
- Controls and local-only guidance are provided in English, Korean, Japanese
  and Simplified Chinese. Unsupported provider-event and live-working-tree
  selections do not offer an inaccurate exact link.

## Upgrade

```bash
brew update
brew upgrade seongwoo-choi/tap/agentrec
agentrec version --verbose
```

Direct Go installation:

```bash
go install github.com/seongwoo-choi/agentrec/cmd/agentrec@v0.14.0
```

## Trust boundary

This is a local navigation link for the same Viewer and recorded data, not a
public share or evidence export. Copying does not upload evidence, send a
message, run an agent command or change recorded artifacts. The link includes
local identifiers or file paths but not action/patch payload contents. A browser
clipboard write already in progress cannot be cancelled by later navigation;
only feedback for the no-longer-current target is suppressed.
